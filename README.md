<details>
<summary><strong>Como instalar ou atualizar no Android</strong></summary>

1. Abra a página da [versão mais recente](https://github.com/xGus0/EduConnect/releases/latest).
2. Em **Assets**, baixe o arquivo terminado em **`.apk`**. Os arquivos automáticos “Source code” não são o aplicativo.
3. Abra o APK e, caso o Android solicite, autorize a instalação para o navegador ou gerenciador de arquivos utilizado. Você pode revogar essa autorização após instalar.
4. Conclua a instalação e abra o **EduConnect**.

**Já tem o aplicativo?** Instale a atualização por cima da versão existente. Se o Android informar incompatibilidade, não desinstale nem limpe os dados automaticamente: procure suporte antes de prosseguir.

</details>

<details>
<summary><strong>Como conferir o arquivo baixado</strong></summary>

Cada release disponibiliza um **`manifest.json`** com os dados da versão e o hash **SHA-256** do APK. Compare o hash do arquivo baixado com o valor correspondente no manifesto.

Baixe apenas pelos links oficiais desta página. A comparação de hashes ajuda a detectar um download alterado ou incompleto; não substitui os cuidados de segurança do dispositivo.

</details>
